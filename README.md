# Sublist3r Engine (`sublist3r_engine`)

A Flutter package for domain infrastructure mapping and subdomain enumeration.

## ✨ Features

- **Subdomain Enumeration**: Discovers subdomains across public OSINT data sources.
- **DNS Analysis**: Resolves domain records and canonical names.
- **Fast OSINT Queries**: Non-blocking asynchronous query pipelines.
