# Sublist3r Engine (`sublist3r_engine`)

A Flutter package for domain infrastructure mapping and subdomain enumeration.

## ✨ Features

- **Subdomain Enumeration**: Discovers subdomains across public OSINT data sources.
- **DNS Analysis**: Resolves domain records and canonical names.
- **Fast OSINT Queries**: Non-blocking asynchronous query pipelines.

## 🚀 Installation

Add this package to your Flutter project's `pubspec.yaml`:

```yaml
dependencies:
  sublist3r_engine:
    git:
      url: https://github.com/AbdoFawzi777/redops-hub.git
      path: packages/sublist3r_engine
```

## 📝 Usage Example

```dart
import 'package:sublist3r_engine/sublist3r_engine.dart';

void main() async {
  print('sublist3r_engine initialized successfully.');
}
```
